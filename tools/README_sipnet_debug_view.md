# SIPNET Debug Log Viewer

Interactive viewer for SIPNET debug log files (`*_envi.log`, `*_fluxes.log`, `*_trackers.log`)
generated by `sipnet --debug-log <prefix>`.

## Features and Requirements

- Reads the three debug log files from a common path/prefix
  - `<prefix>_envi.log` — columns prefixed `envi.` in the Y-axis selector
  - `<prefix>_fluxes.log` — columns prefixed `flux.` in the Y-axis selector
  - `<prefix>_trackers.log` — columns prefixed `tracker.` in the Y-axis selector
- Requires all three debug log files to be present at the given prefix
- Merges the three files into a single timestep-aligned table for plotting
- Uses `year`, `day`, and `time` to build the x-axis
- Plots data columns as requested by the user from the y-axis column selector
  - Excludes `year`, `day`, and `time` from y-axis selections
- Lets you add derived y-axis columns from Python-style mathematical expressions
  - New column names must be legal C/Python variable names
  - When referencing prefixed columns (which contain dots) in expressions,
    use pandas backtick syntax, for example:
    ```
    `envi.plantWoodC` + `flux.photosynthesis`
    ```
- Lets you browse for a log file to derive the prefix automatically
- Supports:
  - combined view with twinned y-axes
  - split subplot view
- Does not redraw on every selection change; redraw happens only when `Apply` is clicked
- Defaults the GUI time range to the full file
- Can pre-populate selected columns and time range from CLI options

## Install

See the install steps in the main [tools/README.md](README.md#install).

To enable tab auto-completion for the `sipnet-debug-view` command, run the following command in your terminal:
```zsh
eval "$(register-python-argcomplete sipnet-debug-view)"
```

## Generate Debug Logs

Run SIPNET with the `--debug-log` option to generate the three debug log files:

```zsh
sipnet --debug-log ./myrun
```

This produces `myrun_envi.log`, `myrun_fluxes.log`, and `myrun_trackers.log`.

## Run Examples

Open the default prefix (`sipnet_debug` in the current directory):
```zsh
sipnet-debug-view
```

Open a specific prefix:
```zsh
sipnet-debug-view -i ./myrun
```

Pre-populate columns:
```zsh
sipnet-debug-view -i ./myrun --columns "envi.plantWoodC,flux.photosynthesis,tracker.t.gpp"
```

Pre-populate time range:
```zsh
sipnet-debug-view \
  -i ./myrun \
  --time-range 2016-001-00.00,2016-010-12.00
```

Use subplot mode:
```zsh
sipnet-debug-view \
  -i ./myrun \
  --columns "envi.soilC,flux.rSoil,tracker.t.rh" \
  --layout subplots
```

To see all options:
```zsh
sipnet-debug-view --help
```

## Notes

- The prefix is the same value passed to `sipnet --debug-log`.
- If any of the three debug log files is missing, the tool exits with an error.
- Invalid `--time-range` or unknown `--columns` fail fast before the GUI opens.
- Empty Apply shows an inline status message and leaves the current plot unchanged.
- Derived column expressions can reference prefixed columns using backtick syntax.
